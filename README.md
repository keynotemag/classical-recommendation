# KEYNOTE Music Type

KEYNOTE의 클래식 음악 성향 테스트입니다.

## 파일 구조

- `index.html` — 테스트 화면
- `style.css` — 기존 디자인/레이아웃
- `script.js` — 질문, 결과 계산, Music DNA
- `README.md` — GitHub Pages 배포 안내

## GitHub Pages

1. GitHub에서 새 Repository를 만듭니다.
2. 이 폴더의 파일 4개를 Repository 최상위에 업로드합니다.
3. `Settings` → `Pages`
4. `Build and deployment`에서 `Deploy from a branch`
5. Branch는 `main`, 폴더는 `/ (root)`로 선택
6. Save
7. 잠시 후 생성된 GitHub Pages 주소에서 테스트를 확인합니다.

※ 기존 배경, 질문, 전체적인 화면 디자인은 변경하지 않고 GitHub에서 관리하기 쉽도록 HTML/CSS/JavaScript를 분리했습니다.
